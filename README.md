# Netflix EDA

This project is an exploratory data analysis of the Netflix Movies and TV Shows dataset.

I used Python and Jupyter Notebook to explore the dataset, clean the data, find patterns, and create visualizations. The main purpose of this project is to understand the Netflix content available in the dataset and practice the basics of data analysis and visualization.

## About the Project

In this project, I looked at different aspects of Netflix content, such as:

* Movies and TV Shows
* Release years
* Genres
* Countries
* Ratings
* Movie duration
* Number of seasons for TV Shows
* Content added to Netflix over time

I also handled missing values and did some basic data cleaning before starting the analysis.

## Tools and Libraries

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

The dataset contains information about Netflix movies and TV shows, including their title, type, director, cast, country, release year, rating, duration, genre, and description.

The main dataset file used in this project is:

`netflix_titles.csv`

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Netflix-EDA.git
```

### 2. Open the project folder

```bash
cd Netflix-EDA
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

Then open:

```text
netflix_eda.ipynb
```

Run the cells from top to bottom.
